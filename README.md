# 扇子 · 网页工具与互动作品

我在制作可以直接使用的网页小工具和互动作品，也在这里记录实现、验证和改进过程。

我的爱发电主页：[扇子](https://afdian.com/a/shanzia)。这个主页由我本人使用，后续会用于发布创作进展和数字作品。

已公开的项目记录：[逃离星海 · 网页试玩](https://github.com/9010qwq/escape-star-sea)。具体内容、素材来源和验证范围以项目说明为准。

正在推进的作品是「生明月」：从两个人的公历生日计算月相，制作月色纪念图与可编辑的六章纪念报告。生日与填写内容在浏览器本地处理。目前已完成本地体验和交付演示，正式收款与在线交付仍在准备中，尚未公开开售。
